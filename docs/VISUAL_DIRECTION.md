# Visual Direction v0.1

## Selected Style

> **Hybrid Pixel Narrative**

The system world and the emotional story deliberately use different visual languages.

## 1. System Layer — Minimal Pixel Base

Use for:

- mission-base map,
- buildings,
- small player / NPC sprites,
- hotspots,
- meter icons,
- compact system UI,
- transitions.

Characteristics:

- clean,
- simplified,
- low visual noise,
- mobile-readable,
- strong silhouettes,
- easy tap targets.

Avoid:

- dense pixel scenery,
- excessive decorative detail,
- tiny unreadable objects,
- nostalgia-first UI that hurts usability.

## 2. Narrative Layer — Hand-Drawn Illustration

Use for:

- character portraits,
- emotional reactions,
- major story beats,
- Boss scenes,
- ending cards,
- share cards,
- special events.

Characteristics:

- expressive faces,
- warm linework,
- richer emotional detail,
- charming imperfection,
- memorable reaction poses.

## 3. Why the Hybrid Exists

Pixel art communicates:

> system / map / project state.

Hand-drawn art communicates:

> people / emotion / narrative meaning.

The contrast should feel intentional.

## 4. Mobile-First Rules

Primary test target:

> ~390 px phone width.

Design for:

- one-handed tapping,
- short reading chunks,
- clear hierarchy,
- practical 44 px+ tap targets where feasible,
- compact but readable cards.

Desktop should use additional space without inventing a separate gameplay model.

## 5. Base Map

MVP locations:

- 🚀 Launch Pad
- 🛠 Engineering
- 📦 Supply Bay
- ☕ Cat Café
- 🏢 Mission Office

Interaction:

1. tap hotspot,
2. tiny movement / transition,
3. event card / scene.

MVP is not free movement.

## 6. Event Card Hierarchy

Top:

- phase / time marker,
- event title,
- small category hint.

Body:

- 2–3 line summary.

Expandable:

- what changed,
- constraints,
- known risks.

Bottom:

- decision actions.

Avoid walls of text.

## 7. Project Meter Presentation

Visible meters:

- ⏰ Launch Window
- 💰 Mission Budget
- 😼 Cat Morale
- 🚨 Mission Risk
- ❤️ Earth–Meow Trust

Prefer:

- icon,
- short status label,
- relative movement,
- simple bar.

Do not expose precise 0–100 values everywhere.

## 8. Evidence Board

Visual metaphor:

> cute mission whiteboard.

Could contain:

- sticky notes,
- paw stamps,
- source labels,
- timestamps,
- crossed / superseded notes.

Do not show numeric evidence reliability.

Conflicts should be visually legible.

## 9. Ending Card

Priority order:

1. PM Style
2. Performance / Judgment
3. mini four-quadrant map
4. Mission Outcome
5. PMP badges

Should work as a shareable screenshot.

Do not make the Ending Card look like an enterprise dashboard.

## 10. PMP Profile UI

Ending Card uses three playful badges:

- 😼 Lead the Cats
- 🚀 Run the Mission
- 🌍 See the Bigger Planet

Tap for detail.

Detailed view uses horizontal bars for skill breakdown.

Coverage on Ending Card may use playful signals:

- 🐾🐾🐾 Well observed
- 🐾🐾○ Still exploring

Detailed screen may use more explicit coverage language.

## 11. Cat Moment Visual Rule

Every Core Event needs at least one of:

- portrait reaction,
- in-world visual gag,
- tiny prop,
- speech bubble,
- memorable line,
- environmental response.

Light events may go further into absurdity.

Core / Boss decisions should remain readable and should not be interrupted by random jokes at the exact moment of a serious choice.
