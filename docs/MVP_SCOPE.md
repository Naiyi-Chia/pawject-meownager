# Pawject Meownager — MVP Scope v0.1

This document protects the first playable release from scope creep.

## MVP Goal

Ship one polished, replayable, mobile-first scenario that demonstrates the complete product concept.

Scenario:

> **Project Meow Homecoming｜喵星返航計畫**

## Must Have

### Core experience

- One complete mission lifecycle.
- Seven major story nodes.
- Two cross-phase story chains:
  - Fake Green / stale information.
  - Burnout / psychological safety / speak-up.
- Five visible project meters.
- Overall Project Status.
- Hidden flags / reactive consequences.
- Simplified mission-base exploration.
- Exploration Action Points.
- One major Boss event.
- Two Boss hidden truths.
- Evidence Board.
- Decision Package system.
- Soft failure + selected hard-fail crises.
- Multiple ending qualities.
- Four MVP PM Styles.
- PMP-aligned People / Process / Business Environment profile.
- Lessons Learned closing.
- Optional PMP Lens.

### Replay

- Semi-random event details.
- Hidden truth selected at run start.
- Reactive dialogue.
- Ending archive.
- localStorage:
  - best score,
  - play count,
  - ending collection,
  - rare-event / Easter-egg collection.

### UX

- Mobile-first.
- Responsive desktop.
- One-handed tap-friendly interaction.
- Minimal pixel base map.
- Hand-drawn narrative illustrations / portraits.
- Short summaries with expandable detail.

## Explicitly Not MVP

- Multiplayer.
- Real-time collaborative play.
- Full free-roaming map.
- Full calendar / day-by-day simulation.
- Backend account system.
- Global leaderboard.
- Ads / monetization SDK.
- Paid currency.
- Live AI-generated Core PMP content.
- Free-text AI-scored answers.
- Multiple industries / scenario packs.
- User-selectable difficulty mode.
- Deep achievement tree.
- Persistent mid-run cloud save.
- Complex equipment / inventory.
- Full AP economy across every PM action.
- Detailed per-character relationship UI.
- Large skill-tree visualization.

## Future Candidates

- Casual vs PMP Prep mode.
- More scenario packs.
- Predictive-only / agile-heavy / hybrid variants.
- Fine-grained PM archetypes.
- Rewarded ads tied to optional recovery.
- More detailed AP economy.
- Achievements.
- Global leaderboard.
- Free-text Boss investigation.
- AI-assisted natural-language decision evaluation.
- Meta progression.
- Scenario difficulty multipliers.
- More hidden truths.
- More industries.
- Share-card generator.

## Scope Guardrails

A feature enters MVP only if it materially improves at least one of:

1. the core project-management simulation,
2. the replayable decision loop,
3. the portfolio demonstration.

If a feature is mainly “nice to have,” move it to Future.

## Session Target

- Quick Run: 8–10 min
- Thoughtful Run: 12–15 min
- Full PMP Lens: 15–20 min

The game should not cut meaningful decision-making merely to hit 10 minutes.
